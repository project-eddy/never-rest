# Plan: never-rest 0.7 Kanon readiness

Mission: ship the review's never-rest backlog (NR-01 to NR-07) as one 0.7.0
minor release with documented breaking changes, so the next knowledge workspace
can build CLI, SDK, MCP and private HTTP adapters on verified principals,
mandatory operation policy, bounded ingress, typed boundary errors, admission
limits and cancellation — without adding runtime dependencies.

Grounding: [research/20261011-never-rest-local-knowledge-review.md](../research/20261011-never-rest-local-knowledge-review.md).

Definition of done:

- NR-01 through NR-07 land with Gherkin specs, tests named after scenario
  titles, CRAP ≤ 8, mutation break ≥ 67, and the type budget ≤ 1,800
  instantiations per route.
- New `./policy` and `./limits` subpaths import nothing from `node:*`.
- `docs/migrating.md` lists every 0.6 → 0.7 break.
- Version is `0.7.0`.

Validation:

```bash
pnpm lint && pnpm typecheck && pnpm test:coverage && pnpm crap && pnpm perf:check \
  && pnpm specs:lint && pnpm docs:snippets && pnpm build && pnpm docs:build \
  && pnpm examples:typecheck && pnpm examples:conformance && pnpm openapi:lint \
  && pnpm exec publint && pnpm exec attw --pack --profile esm-only && pnpm test:mutate
```

## Order

NR-07a → NR-01 and NR-04 in parallel → NR-02, NR-03, NR-06 (after NR-04) →
NR-05 (after NR-03 and NR-06) → NR-07b → 0.7.0 release.

Each item is its own logical slice. The release cut is last.

## Cross-cutting decisions

1. Still no middleware. Policy is a declared map checked at construction.
2. Boundary errors use a reserved `boundary.` namespace. Existing domain codes
   such as `unauthorized` stay valid.
3. HTTP and local share one order and one set of codes. Local errors carry no
   HTTP status.
4. No new runtime dependencies. No classes in new code.
5. Existing gates hold.

## Breaking changes (0.7.0)

- `createDispatcher` defaults to `public` disclosure.
- Request bodies have default size and time limits; the Node bridge streams.
- The `boundary.` namespace is reserved; `ClientErrorOf` is wider.
- Non-JSON error responses are classified by HTTP status.
- `isRetryable` is narrower.
- `dispatch` takes an options object as its third argument.
- `policy` combined with `disclosure` is a configuration error.
- Node 22 or later is required.

## Out of scope

OAuth issuer, user directory, VPN, TLS, firewall, distributed limiter, MCP
transport, QMD integration, Kanon application code, public-message catalogue.
