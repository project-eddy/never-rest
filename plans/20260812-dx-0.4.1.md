# Plan: DX 0.4.1 — membership and contract-wide transport checks

Mission: Close the DX holes a first consumer (Ombo) hit after 0.4 — shared-host path membership, incomplete transport tests, and a few missing recipes — without becoming a framework-adapter suite.

Definition of done:

- `isContractPath(compiled, pathname)` uses compiled `matchPath` (including `invalid_encoding`) so SvelteKit/Workers hosts do not hand-copy paths or use a prefix heuristic.
- `checkContractOutputs(contract, samples)` type-errors when an operation is omitted.
- Docs cover unexpected-fault throws, `ClientInputOf` named aliases, and Query unwrap + `retryable`.
- The SvelteKit example dispatches with `isContractPath`.

Validation:

```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm specs:lint && pnpm examples:typecheck
```

## What stays the same

- `serve()` still always returns a `Response` (including `route_not_found`). No fallthrough mode.
- No TanStack Query package, no `defineContract()`, no params/query/body split.
- Forged `internal` normalisation is unchanged.

## Decisions

- Standalone `isContractPath` (not properties on the `serve()` return value) — easier to type and test.
- 0.4.1 is this slice.
